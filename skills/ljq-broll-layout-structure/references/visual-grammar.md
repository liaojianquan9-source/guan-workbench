# 落定帧排版语法

## 目标

落定帧组件回答六个问题：什么元素存在、在哪里、多大、如何裁切、谁遮挡谁、哪些内容以后可以替换。它描述一个剪辑手法最终到达的视觉状态，不描述到达该状态的运动过程。

## 选择落定帧

按以下顺序选择单帧：

1. 主要元素已经完成入场；
2. 标题、图片、人物或数据的最终阅读关系已经建立；
3. 尚未开始退场、转场或被下一镜头遮挡；
4. 运动模糊、闪白、粒子爆发等瞬时效果最少；
5. 若没有完全静止时刻，选择信息量最大且最能代表稳定构图的帧。

落定帧不是时间上的机械中点，也不一定是镜头最后一帧。记录准确时间码或帧号，避免后续重新猜测基准。

## 画布与坐标

- 继承原视频的横竖方向、宽高比和构图安全区，不强制改为 16:9。
- 记录元素外接框 `[x, y, width, height]`，使用相对画布的百分比；实际可见边界与容器的测量口径按 [static-compositing.md](static-compositing.md)。
- 对文字额外判断左、中、右对齐以及基线关系；对缩放和旋转判断锚点。
- 对贴边、出血或超出画布的元素保留真实裁切，不为了完整显示而缩回画面。
- 百分比用于保持布局关系；需要贴合文字基线、细线和边缘时允许局部像素微调。

## 元素边界

候选内容满足下列任一条件时，建立独立元素：

1. 需要在下一次使用时替换文字、图片、视频或数字；
2. 具有独立位置、尺寸、裁切、圆角、透明度或层级；
3. 与其他内容形成明确遮挡；
4. 后续可能独立入场、退场或运动；
5. 定义容器、阅读边界或视觉中心。

同一媒体内部的普通物体不自动拆分。例如一段实拍中的人物、桌面和麦克风可保持为一个视频元素；只有需要单独替换、抠像或运动时才分层。

## 组件层级

- 每个主要元素使用稳定、可读的名称，例如 `Hero title`、`Subject video`、`Metric number`、`Media card`。
- 共同移动的对象放进命名组；组负责整体位置，子元素负责内部排版与可替换内容。
- `z-index` 顺序必须与原帧一致；同时记录遮罩、overflow、clip-path 或媒体裁切造成的局部遮挡。
- 不用一张全屏截图代替已经能够拆成文字、媒体、形状和容器的构图。
- 不因技术方便添加原画不存在的卡片、边框、阴影或装饰。

## 文字与数字

- 使用参考帧真实内容建立排版基准，同时把可替换文案作为 props。
- 保留字体家族、字重、字号、行高、字距、大小写、换行和对齐方式对布局造成的影响。
- 替换内容时优先保持容器和视觉层级；必要时使用 Remotion 文本测量能力缩放或限制字号。
- 大数字、单位和说明文字若具有不同字号、基线或层级，分别实现但放入同一语义组。
- 高亮、底纹、删除线和局部颜色属于文字内部状态，不自动拆成无意义的独立卡片。

## 图片、视频与人物

- 使用真实媒体元素并保留 `object-fit`、`object-position`、缩放、圆角、透明度和裁切。
- 整帧实拍或不可拆的合成素材可以作为一个媒体元素；叠加文字、贴纸、标题和可替换图片必须独立实现。
- 人物位于实拍视频内时无需画轮廓；需要抠像、独立移动或替换人物时，人物才成为独立图层。
- 透明 PNG、产品图、截图和卡片使用真实素材槽位，不使用写有“图片”或“PNG图”的占位框替代。

## 表格、对话框与正文

- 表格保留真实行列、列宽、行高、表头、分隔线与重点单元格，并把可替换数据参数化。
- 对话框保留容器、头像、文字区和超出画布的关系；共同运动的内容可以组成一组。
- 正文截图若作为一张不可编辑媒体出现，可保持为图片；若文字需要替换，则按实际标题、段落和高亮关系实现，不再简化成“正文内容”框。

## 视觉复核

将 Remotion 落定状态与原始落定帧并排或半透明叠放。核对比例、配色、字体/材质、蒙版或替换适配时，必须使用 [static-compositing.md](static-compositing.md) 的判断顺序与完成证据。这里验收静态终点，时间行为交给后续动效流程。
