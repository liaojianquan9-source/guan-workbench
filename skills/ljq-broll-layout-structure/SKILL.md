# B-roll 落定帧可编辑排版

把参考视频中最能代表最终构图的一帧，直接复刻成可编辑的 Remotion 组件。代码和组件层级是结构表达；不再生成黑白灰语义图或人工风格参考图。

## 开始前

1. 必须先阅读 [references/visual-grammar.md](references/visual-grammar.md)。测量静帧、校准配色/字体/材质、判断蒙版或替换结果前，必须阅读 [references/static-compositing.md](references/static-compositing.md)；它是静态视觉判断的唯一规则来源。
2. 处理多个参考片段时，再阅读 [references/batch-workflow.md](references/batch-workflow.md)。
3. 使用用户指定的 Remotion 插件。写布局代码前加载 `remotion:remotion-best-practices`、`remotion:remotion-markup` 和 `remotion:remotion-interactivity`；需要渲染验收帧时再加载 `remotion:remotion-render`。
4. 优先复用当前项目的 Remotion 工程。不要为了单个落定帧重复创建渲染器。
5. 不要求用户提供坐标、JSON 或组件代码；由 AI 查看原视频或用户指定的静帧后完成测量和实现。

## 落定帧

落定帧是图片或文字完成主要入场之后、开始退场之前，最完整表达该镜头排版关系的单帧。

- 每个镜头默认只选择一帧，不再制作开始、中间、结束三张结构图。
- 优先选择主要元素全部可见、遮挡关系清楚、构图已经建立的时刻。
- 若画面一直缓慢移动，选择信息最完整、最能定义最终位置关系的一帧，并记录源时间码与帧号。
- 若用户已指定静帧，直接把它作为落定帧，不另行替换。
- 原始静帧是复刻依据，不是要重新生成的风格资产。

## 工作流

1. 查看原视频的目标区间，确认镜头边界、画幅、帧率，并选出落定帧。
2. 判断画面家族与一至两个视觉中心；三个是上限。
3. 拆元素和填写属性前，读取 [references/element-taxonomy.md](references/element-taxonomy.md)，按对象类型与共享/专属属性两轴分析。把落定帧拆成真正需要独立定位、替换、遮挡或后续运动的元素和组，并保留适用属性与未知项。
4. 为每个元素确定百分比位置与尺寸、对齐基准、锚点、裁切、圆角、层级和父组；保留原画的留白与超出画布关系。
5. 直接用 Remotion React 代码复刻最终构图。每个主要元素使用可辨识名称和可交互标记，使其能在 Remotion Studio 中被选择、拖动、缩放、旋转和修改样式。
6. 把下次会替换的文字、图片、视频、数字和主题色暴露为 props；需要在 Studio 中编辑时使用 Zod schema。不要过早把每个几何常量都抽成全局模板参数。
7. 组件默认状态必须等于落定帧。此阶段不发明入场、出场、弹跳、转场或特效时间曲线。
8. 用 Remotion 渲染单帧进行视觉对照。验收图只是临时检查结果，不作为下游参考图或案例主体。
9. 发现偏差时按 [静态视觉判断](references/static-compositing.md) 的顺序修正，每轮处理最高影响问题或同根因问题组，并记录剩余差异。

## Remotion 实现约束

- 独立元素优先使用 `Interactive.*`；媒体使用 Remotion 对应的图片或视频组件，并给出可识别名称。
- 为了能在 Studio 中编辑，位置、尺寸和样式尽量写在元素的内联 `style` 中；不要把可编辑样式藏在复杂计算、对象展开或不可追踪的 transform 字符串里。
- 位置优先使用画布百分比表达，必要时使用像素完成边缘、基线或字体微调。
- 可编辑的位移、缩放和旋转分别使用 `translate`、`scale`、`rotate`；只有顺序敏感或透视变换才使用组合 `transform`。
- 文字默认使用参考帧中的内容建立基准，再把可替换文案暴露为 props。使用与渲染一致的字体属性测量文字，防止替换后溢出。
- 不把整个落定帧当作一张背景图片铺满画布。只有原画本身就是不可再编辑的整帧实拍或合成素材时，才把它保留为单个媒体元素。
- 同时移动、裁切或缩放的多个子元素可以组成一个命名组，但仍保留需要替换的内部内容。
- 保留水印或平台标识只在用户明确要求时进行；默认不把它们实现为可复用元素。

## 输出

- 一个可复用的 Remotion React 组件，默认呈现与落定帧一致的最终状态。
- 对应的 props/schema，至少覆盖会被下一次案例替换的内容和素材。
- 一条来源记录：参考视频、镜头区间、落定时间码或帧号、画幅与帧率。
- 按需生成一张 Remotion still 作为视觉验收；验收后无需把它当作模板资产保存。

不要调用图像生成模型，不要生成黑白灰结构图，不要创建风格参考图片。静态材质与动态效果按 [静态视觉判断](references/static-compositing.md) 区分；完整入场、出场、转场和效果时间行为由后续动效复刻流程围绕本组件的最终状态实现。
