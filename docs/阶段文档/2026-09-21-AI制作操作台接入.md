# AI制作操作台接入与验证 · 2026-09-21

用户认可 4185 前端交互提案的布局，要求它成为 4182 现有 AI工作台的“AI制作”页面，并接入已有制作引擎、Agent 检索、共享库和真实预览。4185 原提案保留为历史证据，不再是产品入口；4182 的其他研究与复刻功能仍在原位置。

## 决策、依据、取舍、验证

| 决策 | 依据与取舍 | 验证结果 |
| --- | --- | --- |
| 用截图的三栏和三轨时间线作为 AI制作工作面 | 用户明确指定该界面；沿用原操作台 CSS 视觉语言，改为真实项目数据而非重做另一个产品 | 4182 宽屏实际展示 8 张原项目卡、53 秒真实口播、逐段证据、底部三轨时间线；窄屏按原提案折叠 |
| 使用独立共享资产服务已有样式，不搬运 Demo 的假样式记录 | 静态提案里的 3 个设计是交互样例，没有可复用的渲染资产；共享服务中有 3 个技术验证通过的实际样式 | 页面读取到月球标题、重点数字、照片背景 3 种真实样式及 1 张图片；替换参数固定资产 ID 和版本 |
| 将时间线和画幅选项写入项目版本 | 原 Demo 拖动、转场仅内存模拟；产品需要实际审片、旧预览失效、重新确认 | 副本 c004 从 23.4–27.8 调成 23.5–27.7，修改裁切与淡入淡出；预览失效并重渲染，版式通过后确认 |

| 未确认的样式不进入成片；当前版本不匹配时隐藏旧成片入口 | 避免旧预览、旧交付冒充当前效果 | 副本完成 53.033 秒 H.264/AAC 成片，1080×1920，报告记录 `contain` + `dissolve`；旧版本改变后不会被当前审片清单当作有效成片 |

## 本地使用

运行 `prototypes/broll-workbench/start.command`，打开 <http://127.0.0.1:4182/?project=4d54541e7863421298b8731216accaea&view=ai-making>。顶部“＋”将当前口播导入新制作项目；无字幕的视频先在“拉片”转文字。左侧选择或批量审看，右侧看证据、换共享样式与字段、调整效果；底部拖动 B-roll 后需重新生成实际预览，再由用户确认。审片清单可展开 Agent 真实工具调用记录、另存副本、预览所选以及渲染已确认片段。共享样式可跨制作项目选择；图片可批量导入独立资产库。

验证使用独立项目 `b54892bebd9946aea6f08ef9e31df7f2`（“AI制作界面验收副本 · 2026-09-21”），原项目 `23db4d3f88134c4fb51d0fd54d346698` 未被本轮批准或渲染。验收副本先产生一次不合格的铺满交付供问题取证；再改完整画面、重新预览/批准/渲染，最新交付为 `final-dc449b8274e7448ea597042b5d373c64.mp4`。历史交付保留用于追溯，当前审片清单只展示与已确认卡片一致的版本。

验证命令：在 `prototypes/broll-workbench` 目录运行 `node --test tests/*.cjs`（107/107）与 `PYTHONPATH=. python3 -m unittest discover -s tests`；在 `apps/broll-agent` 目录运行 `python3 -m unittest discover -s tests`（76/76）。真实片的缩放、转场、预览、合成和音轨用实际 FFmpeg 输出核对。

当前限制：现有可复用案例是横版。完整画面虽文字可读，却有明显上下留白；产品不会把它说成视觉验收通过。若要达到提案里竖屏满幅的设计，需要额外制作适配竖屏的样式版本并让用户审看。任意新参考片的自动复刻仍未达到验收标准，不在本次界面接入中冒充已完成。
