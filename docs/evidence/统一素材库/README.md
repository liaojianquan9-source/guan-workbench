# 统一素材库 · 核对步骤

工作台地址：<http://127.0.0.1:4182/?view=assets&tab=images>

1. 打开工作台。侧栏应看到「首页、拉片、AI复刻、AI制作、素材库、设置」，不再并列「画面」和「声音」。
2. 点「素材库」。页内有「图片 | 音乐」。图片页能切换「分镜 / 收藏」，下面有「复刻样式」。
3. 点「音乐」。能搜索，识曲结果和本地曲库分开，仍可导入音乐。
4. 打开一条视频的拉片。右侧仍是「分镜、图片、字幕、音乐」，操作留在当前片里。
5. 打开 AI制作。样式区标题是「来自素材库」，「在素材库中打开」回到图片页，不离开这个工作台。
6. 旧链接 `?view=frames` 进入图片，`?view=music` 进入音乐。

本次自动核对用了一份临时样例服务，没有改用户资料。桌面与窄屏截图：

- `desktop-images.png`：素材库图片页，含拉片画面、可制作样式和替换图。
- `desktop-music.png`：识曲结果与本地曲库分开。
- `desktop-home.png`：首页仍是视频项目。
- `desktop-analysis.png`：拉片右侧仍是当前片的研究资料。
- `mobile-images.png`：390 宽仍能切换图片和音乐。
