# 拉片功能范围

以本地固定版本拉片宝源码的活跃功能和界面操作为基准，沿用现有工程自行实现。用户已明确要求全部对齐，不再逐项请求确认或擅自缩减。

- 本地上传视频；视频库、搜索、排序、标签。
- 播放、逐帧、镜头跳转、快捷键。
- 本地自动识别镜头，画面时间轨与展开的分镜网格。
- 音频波形、入点出点、声音截取、字幕识别与逐句定位。
- 截图、时间点笔记、图片及声音收集、六色色板、来源回跳。
- 联网识曲、识别状态与重试、音乐列表。
- 原有文档导出、持久化、缓存与失败恢复。
- 播放器居中，右侧素材收集，底部画面与音频双轨；按源码对齐展开、弹层和键盘操作。

只有链接下载按用户明确要求排除。不增加手工改切点或其他后续工作区。

当前工作台未完成全部对齐。已删除扩展页面及对应演示代码、旧方案和旧原型；已有视频和分析记录保留。验收必须区分源码里有、接口已实现、界面已接通、真实运行通过。
