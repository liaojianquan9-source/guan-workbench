# B-roll 语义排版结构图 Skill 设计

## 目标

创建 `ljq-broll-layout-structure` Skill，把一张或一批 A-roll/B-roll 截图抽象为低噪声的黑白灰语义排版图。界面显示名为 `LJQ-broll-layout-structure`。输出不是原画复刻、HTML 线框、JSON 展示或视频，而是让后续多模态 AI 快速理解画面中的位置、比例、层级、遮挡、视觉中心和内容类型。

## 架构选择

Skill 使用“轻入口＋按需参考＋风格资产”结构：

- `SKILL.md`：触发范围、主流程、输出要求和停止条件。
- `references/visual-grammar.md`：元素取舍、灰度层级、文字/正文/表格/人物/背景图/PNG/重点/框线等非显然规则。
- `references/batch-workflow.md`：批量输入、逐张检查、连续帧锁位、文件命名、保存和汇总检查。
- `assets/`：少量已经验证的结构图，用作风格参考，而不是固定模板。

不添加自动识图脚本。当前任务的关键是语义判断，过早脚本化会把人物、背景图、正文块和重点状态写死。图像生成保持“一张输入对应一次生成调用”，允许并发，但每张使用独立提示词。

## 数据流

原始截图 → 识别画面家族与视觉中心 → 筛除水印、字幕和非独立运动物体 → 估算百分比位置与比例 → 选择最少语义元素 → 使用原图作为构图参考、风格资产作为样式参考生成 → 视觉复核 → 非破坏性保存 → 批次汇总。

连续镜头共享同一基础坐标，只改变显隐、重点范围、缩放或焦点状态。正文量很大时不用逐行文字，而用一个浅框标注“正文内容”。

## 错误处理与验证

若无法判断某物是否是独立元素，检查它是否影响位置、尺度、遮挡、视觉中心或独立运动；全部否时并入背景。生成后检查：16:9、无品牌与字幕、无具体文案、文字无乱码、灰度层级正确、元素比例接近原图、连续帧未漂位。失败时每次只修一个问题并保留旧版本。
