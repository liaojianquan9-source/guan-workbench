# AI工作台的制作引擎与共享资产

用户入口继续使用现有 [AI制作](http://127.0.0.1:4182/?project=4d54541e7863421298b8731216accaea&view=ai-making)。4183是内部制作引擎，4184是独立共享资产服务。

## 启动和验证

双击原工作台的 `../../prototypes/broll-workbench/start.command` 即可一起启动三个本机服务；这里的 `start.command` 也调用同一个启动器。已有进程不重复启动，启动器退出只停止它自己启动的服务。

运行这里的 `verify.command` 检查资产、Agent、接口、渲染、恢复和界面契约；再运行原工作台的 `verify.command` 检查现有页面和拉片回归。真实生产验收脚本在 `tools/verify_real_production.py`，运行会另建测试副本并标记acceptance-test，不能当作用户审批。真实模型运行需本机Codex已登录；默认模型由provider配置，可用性见 `/api/status`。

## 当前能做什么

现有AI制作页可找回持久化草稿；Agent基于视频、字幕、固定版本样式预览、素材检索和用户历史执行有限循环。真实口播已验证比较候选、指出素材缺口、保留不适合覆盖的人脸段落、渲染检查失败后修改并复检。用户批量修改会使旧审批与预览失效。

三个已经适配的真实样式可从原案例导入共享库，在另一个制作项目替换文字/图片并实际渲染。整片合成保留原片尺寸、帧率和声音。媒体检查、版式检查和人工保真审看分别记录。

新参考可建立研究/复刻任务，Skill阶段在隔离目录执行，产物与恢复包存入共享库。任意参考的布局、动效与保真全链路尚未全部验证；此能力不能标记完成。横版样式在竖屏的留黑效果仍待用户决定适配策略。

## 数据与恢复

- 原研究项目：现有工作台选择的资料库，导入只读取原视频/字幕。
- 共享资产：`~/Documents/BrollAssets`，内容哈希文件、不可变资产版本和关系；不同产品通过独立HTTP接口共用。
- 制作项目：`~/Documents/BrollProjects`，SQLite保存项目、任务、操作事件和人工决定；`files/`保存实际预览/成片。
- `BROLL_ASSET_ROOT`、`BROLL_PROJECT_ROOT`可指定测试或迁移后的独立目录。迁移前保留完整副本；不直接覆盖正在使用的数据。
- 共享库备份接口 `/api/production/assets/export` 返回包含所有版本与二进制的ZIP；制作项目 `/api/production/projects/<id>/export` 保存方案与固定引用。原工作台的“导出整个资料库”目前只覆盖原研究库；共享库和制作目录需同时备份，不能误认为已包含。
- 任务失败保留草稿和事件，可继续运行。服务重启将未完成任务记为可恢复中断，不伪造成功。

本轮分段验收和待定判断统一保存在根目录 `docs/项目状态.md`。详细接口、渲染限制及来源证据位于 `docs/`。
