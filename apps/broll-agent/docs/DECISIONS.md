# 决策与验证记录

## 2026-09-21：入口判断修正

**依据**：用户指定现有产品入口 `http://127.0.0.1:4182/?project=4d54541e7863421298b8731216accaea&view=ai-making`，指出已经有产品，需要修复现有问题。

**判断错误**：第一轮把“独立资产层”扩大成“另一个独立产品界面”，在4183另建界面，偏离现有产品。用户不应被迫迁移，也不应反复纠正名称。

**修正**：4182现有AI制作页面是唯一产品入口。保留既有导航、输入区、分镜卡与选择替换区域；把底层Agent、资产和渲染接回原页面。4183作为后台制作引擎，根路径返回4182。4184仍是独立共享资产服务。产品名称按用户指定“AI工作台”，不发明品牌。

**验证**：实际浏览器已打开用户指定URL。命名检查、后台根路径重定向、同源接口与媒体代理纳入测试。后续只在4182验收用户旅程。

## 资产域与制作域

**依据**：旧草稿只在localStorage；旧整库备份不包含AI上传图片；两案例自动保真待审。旧project.json承担研究，不适合作为跨产品资产目录。

**取舍**：保留拉片存储，在旁路新增SQLite版本化共享资产服务。媒体SHA256寻址，asset revision不可变，制作项目固定引用版本。源片研究、复刻任务、可用样式、图片与制作项目分别存储、保留关系。无需现在引入云数据库和账户体系。

**验证**：两个HTTP客户端跨产品读取同一资产、CAS冲突、固定旧版本、Range、备份恢复均通过；3个真实样式已将源码包、来源、预览、替换报告存入共享库。技术通过与fidelity待审始终分开。

## Agent与模型

**依据**：本机Codex已登录；独立API key未配置。官方文档支持非交互结构化输出及图像。现有AI制作只有七条关键词规则。

**取舍**：本机Codex只返回结构化产品动作，产品控制工具、状态、记忆、重试、并发、审批。选择当前可调用的gpt-6-astra，低推理档；不把无模型的规则回退包装为智能。模型不可用保留草稿，可继续手动编辑。

**验证**：真实53.03秒口播完成8轮动作、24条事件：看视频、查3个样式、读取真实预览、读历史、查图片、提案、真实渲染、检查。25段字幕生成8张卡：6保留、1素材缺口、1B-roll。所有卡仍为草稿，未替用户批准。

## 渲染检查修正

**依据**：首次模型把6字副标题放进原本163×119的K3区域，媒体可解码但字被压得太窄；模型未主动指出。

**取舍**：媒体合法性不等于版式可用。新增确定性文字密度门，layout.needs_revision阻止批准与finish。真实Chrome字体探针分别记录子集命中/系统回退；新中文不再声称仍是原字体。审看预览放入口播实际画幅与声音，保留原生B-roll供最终合成。

**验证**：6字副标题稳定触发需修订，4字“用好AI”通过。修改使旧确认/预览失效；固定样式从共享源码ZIP恢复并验清单、逐文件哈希、依赖和适配合同，防止旧版本随本地源码漂移。
