# AI 工作台：前端交互提案

这是**独立的纯前端 Demo**，用于让用户先判断操作逻辑；不是 4182 产品的替代入口。没有 API、后端、项目写入、模型调用或真实渲染。刷新页面会恢复演示状态。真实口播被压成 270×480、15fps 的 53 秒本地预览代理文件；所有 B-roll 叠加均由前端 CSS 模拟，不能当作最终视频效果验收。

运行：在仓库根目录执行 `python3 -m http.server 4185 --bind 127.0.0.1 --directory prototypes/ai-workbench-ux-demo`，打开 <http://127.0.0.1:4185/>。静态文件服务只用于打开网页。测试：`cd prototypes/ai-workbench-ux-demo && npm test`。不需要安装依赖。

操作路线：左侧点一段 Agent 判断，预览和时间线跳到相同位置；右侧看依据，切到“样式与动效”可替换、调转场与竖屏处理；下方拖片段或两端调整时间；左侧勾选多段批量保留/采纳；撤销、重做、播放、缩放和审片清单可直接试。顶部“参考研究”“共享样式”用于表达跨项目资产的入口关系，这两页仍是交互说明，未执行复刻和入库。

本页所有关于 Agent 的解释、匹配和素材缺口为**根据真实口播编写的设计样例**，不是实时推理。真实口播的字幕识别可能有错字，演示文案根据原意略作缩写。
