# 观 · 本机工作台

在现有拉片工作台中研究参考、查看复刻任务，并对口播生成可审改的制作草稿。沿用原项目和导航；AI制作与共享资产的后端能力接在同一个入口。

## 打开与使用

双击 `start.command`，保持终端窗口打开，再访问 <http://127.0.0.1:4182/?view=ai-making>。启动脚本会先用稳定的 Python 3.12 检查三套本地 AI 环境；失效的解释器会自动修复，依赖不完整时按锁定清单补齐。随后一起启动工作台、内部制作引擎和共享资产服务，已有服务会继续复用，只有本次启动的进程会随窗口停止。服务只监听本机。

1. 点击“导入视频”，选择本地视频；可多选、选文件夹或拖入。
2. 展开播放器下方“画面”轨，自动识别镜头；点击镜头回到原视频，方向键逐帧核对。
3. 展开“音频”轨，生成带时间的字幕。点字幕定位；字幕可能有错字，请回听核对。
4. E 保存当前画面；点击镜头只定位到该镜头起点。打开已保存研究片段后，播放按该片段自身的 `start` / `end` 进行。
5. 在当前时间点记笔记，给视频、图片、历史声音和歌曲加标签。音乐段的“试听本段”使用独立临时范围，不改变研究片段。
6. 侧栏「素材库」用「图片 | 音乐」查看跨视频可复用的拉片画面、已通过技术检查的复刻样式，以及识曲结果和本地音乐。图片里仍可切换分镜与收藏、搜索和标签；音乐可试听、回跳来源或导入。拉片右侧仍是当前片的分镜、图片、字幕、音乐。旧地址 `?view=frames` 与 `?view=music` 会打开对应分页。
7. “导出分镜表”生成带真实镜头图的 Word；字幕可导出 Markdown、SRT、纯文本。
8. “复刻”页保留左任务、中静帧、右审查。任务来自共享库中的研究/复刻记录，能建立选段研究并运行Skill阶段。没有实际复刻帧时明确显示缺失，不拿原图冒充；审查绑定真实产物版本。任意新参考从布局到动效和保真的完整流程仍待验证。
9. “AI制作”读取当前视频字幕、上传口播或输入文稿；Agent查看视频、比较样式、查素材和历史，提出保留口播、添加画面或素材缺口。草稿保存到服务端。可多选卡片、批量导入图片、替换固定版本样式/元素、生成实际预览，审看后批量确认或舍弃。修改会撤销旧预览和确认。确认的画面才能进入完整视频；仅文稿的估计时间不能直接导出成片。

视频库支持搜索、来源筛选、多个内容标签同时筛选、排序及调整宽度。窄窗口收起视频库和收集区，点击对应按钮打开。设置中可查看运行环境、工作台当前使用的内存（MB / GB）与修改快捷键。

## 实际使用的处理方式

| 能力 | 实现 | 是否联网 |
| --- | --- | --- |
| 播放、逐帧、缩略图、截图、波形与片段声音处理 | 浏览器播放器与本机 FFmpeg / FFprobe | 否 |
| 自动找镜头 | TransNetV2，本地专用模型 | 否 |
| 语音转字幕 | whisper.cpp v1.8.3 + large-v3-turbo q5_0，优先 Metal，失败回退 CPU | 否 |
| 歌曲识别 | shazamio 本地生成音频指纹，向 Shazam 查询，再向 iTunes 查询歌曲资料 | 是 |
| 色板、标签、笔记、搜索、排序、导出 | 普通程序 | 否 |
| AI制作的判断、候选比较、渲染后修订 | 本机已登录的Codex模型；公开工具步骤与结果持久化 | 是，发送任务文稿及抽帧用于模型分析 |
| 样式替换、预览与完整视频合成 | 本机Remotion与FFmpeg，按固定资产版本执行 | 渲染本身在本机 |

基础拉片不需要大语言模型API Key。AI制作当前使用已登录的Codex账号，消耗该账号的额度；不可用时保留已有草稿并提示重试，不用关键词规则假装模型。首次安装依赖、获取模型需要网络；当前机器已准备好。歌曲识别需要网络且不保证每段都匹配；失败和无结果分别显示，不填示例歌曲。识曲使用每段 12 秒的采样，最多 12 处，并保留匹配位置。

自动分镜默认阈值 0.35，最短镜头为 `max(0.3 秒, 8 / fps)`，在镜头开始后约 0.08 秒取缩略图。模型结果需要人工核对。原有笔记、截图和历史声音资料独立于模型任务。

## 文件与环境

- `data/<项目ID>/source.mp4`：兼容的视频原样复制；其他格式保留 `original-media` 并生成可播放副本。
- `project.json`：镜头、来源、标签、时间点笔记、字幕、识曲和任务状态。
- `thumbnails/`、`captures/`、`exports/`：当前实际输出文件；`audio/` 只保留历史独立声音片段兼容。
- `waveform.json`、`previews/`：本地预览缓存。
- `data/music/` 与 `music-library.json`：导入的本地音乐及信息。
- `.venv/`：TransNetV2；`.venv-separation/`：UVR 声音分离；`.venv-music/`：Shazam 依赖；`runtime/whisper.cpp/`、`runtime/models/`：Whisper 程序与各本地模型。

同一资料库同一时间只允许一个工作台进程打开。项目记录使用原子替换、有效备份和 schema 版本；主记录损坏时会保留现场并尝试用最后一份有效备份恢复。这一代本地备份用于抗单次写入失败，不替代外部备份。

单个上传最多 20 GB。支持 FFmpeg 可读取的视频；需转换的文件会显示处理状态，无法解码会明确报错。电脑上的原文件不会被改动。根据当前产品决定，不增加独立回收站；界面的“移除”继续隐藏记录、保留项目文件，并在提示中提供即时撤销。现有完整导出与迁移见下面的“可搬运资料库”。

当前是本机网页开发版。文件可保存到电脑、通过访达定位；浏览器拖文件到其他 Mac 应用的兼容性尚未验收。开发阶段暂不制作 Apple / Mac 独立安装包，也不因发行平台提前收窄依赖锁定。

## 验证

双击 `verify.command` 可重跑现有工作台的语法、Python后端/存储、前端行为回归，并真实导入三套本地AI环境；制作引擎与共享库另运行 `../../apps/broll-agent/verify.command`。以实际运行输出的通过数量为准。自动测试在临时目录生成媒体，不修改用户资料。当前阶段状态和用户待定判断见根目录 `docs/项目状态.md`。

2026-09-19 最终验收另外真实运行了 TransNetV2、Whisper large-v3-turbo 和 UVR 声音分离，并用真实浏览器验证恶意项目名仅作文字显示、分镜调用、HQ/SQ 切换与退出行为。接口见 `docs/backend-api.md`。

## 已保存研究片段（2026-09-19）

点击原片镜头只定位到镜头起点，不创建临时选区或新研究片段。打开已保存研究片段时，播放使用该记录自身的 `start` / `end`；其关键画面、原音 / 人声 / 背景声、范围内字幕和时间点笔记仍可继续查看与编辑。

研究片段保存来源与时间范围，不自动生成新 MP4。PNG / WAV 的实际中文文件名、目录和“在访达中显示”位于片段详情。改名不移动已有文件；调整开始/结束时间保留旧声音结果和范围外的画面/笔记。

手动入点/出点、时间轴拖拽选区与“保存选区声音”已下线，不再新建独立选区音频。历史 `audio_clips` 仍在“音乐 → 已保存音频”中兼容显示，可试听、下载、回到来源位置或移除记录。

- 后端：`research_clips.py`（记录、命名、文件、声音任务）；前端：`public/clips.js`（操作与播放）、`public/clips.css`（外观）、`public/clip_logic.js`（时间规则）。
- 声音分离：`.venv-separation/`，audio-separator 0.47.0，固定模型 `UVR-MDX-NET-Inst_HQ_3.onnx`，本地按片段运行；模型在 `runtime/models/separation/`。依赖版本见 `requirements-separation.lock.txt`。MPS / CoreML 失败会重试 CPU；原音始终可直接播放。
- 新环境安装：`start.command` 会使用稳定 Python 3.12 按锁文件检查或创建三套环境。全新机器第一次补齐依赖需要联网；缺少 Python 3.12 时会明确提示，不会改动项目资料。
- 验收记录：`docs/research/2026-09-18-clip-flow-verification.md`。


## 可搬运资料库（2026-09-19）

- 单个项目：首页视频卡片的“⋯ → 导出完整项目”。选择移动硬盘上的文件夹，直接复制并校验，不在本机先生成压缩包。
- 整个资料库：“设置 → 资料存储 → 导出整个资料库”。包含所有项目（包括已隐藏的项目）及本地音乐、标签。
- 释放空间：在已完成的导出任务中点“释放本机空间”，确认后重新校验目标副本和本机内容，再删除本机项目文件。导出后有修改会拒绝释放，必须重新导出。
- 恢复：把完整导出文件夹拖入工作台，或在“设置 → 恢复资料”选择文件夹。原视频、字幕修改、分镜名称、切点、图片、声音、笔记和导出文件一起恢复，不重新识别。完全相同的项目跳过，不同版本不会覆盖。
- 更换位置：“设置 → 更换位置”选择空文件夹。完成复制、校验后切换，旧目录由用户主动释放。请将正在进行的分析或编辑先完成。

项目包为普通文件夹：`项目清单.json` + `项目资料/<项目ID>/...`，整库包的项目资料中另含 `music/`、`music-library.json`。内部沿用现有目录。清单包含版本、相对路径、文件大小和 SHA-256；播放代理、预览、波形缓存、日志和临时文件不搬运。软件、模型和运行环境不属于资料包。

后续方向是将“单个项目＋全部关联文件”制作成一个便于放入云盘的打包文件。当前暂不实施；压缩格式、版本、增量规则和恢复流程等进入该阶段后再定。

全新安装默认保存到 `~/Documents/拉片资料库`。旧安装继续读取原 `data/`，直到用户通过设置迁移。选择的位置记录在 `~/.config/lapian-workbench/storage.json`；外置资料库不可用时不会悄悄创建新库。显式 `--data-dir` 用于隔离测试并优先于配置，该次运行的迁移不改写全局配置。

存储任务期间暂停资料写入；操作可取消，进入最终提交阶段后不可取消。导出收据保存在本机隐藏记录中，重启后仍可重新校验并释放空间。导出的文件夹以后可以改名和搬动；释放本机空间之前请保持其位置不变，否则需重新导出以建立新的校验记录。

存储、恢复、释放空间、迁移中断、并发请求与内存采样已纳入当前 94 项后端回归。全部破坏性验收仅在临时测试资料库进行。


## 轨道与研究资料定位（2026-09-19）

点击文字、画面或音乐轨道时，如果右侧已经打开对应的字幕、分镜或音乐栏目，会滚动到对应条目并短暂描边。只滚动右侧列表，不抢键盘焦点，不切换其他栏目；字幕编辑草稿保留。字幕定位取起点之后的第一帧，避免帧取整使高亮落在前一句。4 项定位行为测试已纳入当前 77 项前端回归。


## AI制作原生入口（2026-09-21）

打开`prototypes/broll-workbench/start.command`，进入 4182 深色 AI工作台，点左侧「AI制作」。本模块保留原工作台导航，原片、草稿、共享样式、图片导入、时间线调整与渲染都在当前页面操作。4183 / 4184 只作为内部制作引擎和共享资产服务；Demo 操作台不再加载。

已有视频会按来源读取真实制作草稿。「文稿、导入与 Agent 执行记录」可展开输入、选择同源制作副本或查看推理/工具记录。选中时间线片段后，右侧编辑样式与元素；可以批量导入图片、勾选多卡应用替换、预览和确认。没有合适素材的卡仍显示缺口。

B-roll 可以在时间线上拖动或拉伸两端，也可以填写精确起止时间，选择完整显示/铺满和直接切换/淡入淡出。保存调用已有制作接口，会使旧预览和确认失效。先生成、审看实际预览，再确认并生成审阅成片。未保存字段会阻止误确认；历史成片与当前版本不一致时显示需重生成。

本轮撤回 AI复刻的误放改动，该模块继续使用已有真实参考、阶段任务与静帧审查。使用 `./verify.command` 验证工作台，制作引擎使用根目录 `apps/broll-agent/verify.command`。产品效果仍需用户审看。
