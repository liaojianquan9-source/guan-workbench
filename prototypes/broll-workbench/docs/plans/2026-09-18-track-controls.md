# 轨道图标与控制

按用户明确指定的剪辑器操作修正轨道头：播放器、人头、小喇叭标识三层；每层提供锁定、显示/隐藏、静音、S 单独播放。只留图标，名称和说明放在悬停提示及辅助阅读标签。

- 上方统一播放/暂停。点轨道仅定位，不自动更改听哪一层。
- 静音是每轨独立开关；S 是互斥单独播放，解除后恢复其它轨道各自的静音设置。静音优先于 S。
- 初始 S 选中原片段，避免三层默认一起响；取消 S 后按各轨静音开关混合播放。
- 隐藏原片轨同时隐藏画面预览及该轨内容；隐藏声音轨仅隐藏波形，声音由静音控制。轨道头始终保留，方便重新显示。
- 锁定防止该片段共同起止范围被修改、片段被移除；仍可定位、播放和保存研究记录。
- 轨道状态按片段保存在当前浏览器本机；保持现有资料结构和声音文件。
- 验证路由组合、静音优先、Solo 解除、锁定保护、显示与声音分离、双分离轨同步、刷新恢复。
