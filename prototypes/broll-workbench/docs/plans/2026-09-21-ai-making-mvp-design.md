# AI制作 MVP

## 目标与呈现

左侧导航增加「AI制作」。输入口播文稿、上传语音，或读取当前视频的已识别字幕后，工作台按句或按段生成分镜卡。每张卡把视觉预览放在上面、对应口播放在下面；右侧保持一个视觉预设库和当前句的替换字段。点选预设、改文字或选择本地图片、确认即可留下这一句的决定。

## 数据与处理

- 视觉来自现有 B-roll 样式库的 `SHOT-001` 至 `SHOT-007`，预览文件作为真实素材副本打包在 `public/ai-presets/`。无匹配时建议保留口播，用户始终可以手动换镜头。
- 语音使用本机已有的 Whisper 适配器转写；视频字幕沿用当前项目。拆分同一字幕段的多句时，句内时间按字符数估算，并标出「估算」。纯文稿没有时间码，界面显示「时间待定」。
- 初版推荐用可检查的关键词规则。它不调用聊天历史或大语言模型，也不声称已判断完整叙事；人工确认每句的视觉。
- 草稿暂存当前浏览器的本地数据中，按当前视频项目区分。导出 JSON 包含原句、时间、镜头 ID、确认状态和替换字段。
- 上传的替换图片只保存到本机工作台资料目录 `ai-making-assets/`；预览仍显示原镜头示例，替换内容此时只是分镜方案的一部分。

## MVP 边界

本版用于验证「一句口播对应一张可修改的视觉卡」是否顺手。它尚未把新文字或图片重新渲染成镜头，也未把镜头合成进成片。后续接入复刻模板的参数映射与 Remotion 渲染时，可继续使用这份分镜方案，而不需要让用户写提示词。

## 验证

前端测试覆盖切句、时间分配、匹配和预设文件；后端测试覆盖本地语音入口、图片保存、媒体范围读取及路径限制。浏览器检查了文稿切句、预设更换、保留口播、确认与刷新保存；另用 5 秒真实口播验证本机 Whisper 转写和时间码。
