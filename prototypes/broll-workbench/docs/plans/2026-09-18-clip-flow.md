# 拉片片段流程实现计划

> **⚠️ 历史记录：I/O 已于 2026-09-19 下线、仅作当时留档。**

**目标：** 在已有拉片页走通圈定范围、命名保存、多张关键画面、声音回听、笔记及重新打开恢复。保留现有视觉样式，不增加复刻工作区。

**结构：** 片段记录保存来源绝对时间；新增独立 research_clips.py 与 public/clips.js、clips.css，已有工作台只增加接口和渲染入口。普通操作使用代码，声音分离作为按需本地任务。旧项目无需迁移。

**环境：** 本机 macOS、Python 3.12、FFmpeg、原生浏览器 JS；声音分离单独运行环境。

1. 新增片段记录、连续序号、校验与独立修订号，防止旧页覆盖；测试跨镜头范围、无声视频、重开恢复。
2. 实现中文安全文件名和多张 PNG 关键画面；同时间截图幂等，重命名不移动旧文件；测试来源时间、尺寸及路径安全。
3. 实现片段原音与人声/背景声任务、取消、失败重试、缓存及时间长度检查；实测样片，不把推理成功当成分离质量验收。
4. 接入 I/O 保存片段、右侧片段列表/详情、关键画面/声音/字幕/笔记，点击返回来源，片段播放与整片退出。
5. 以视频为播放时钟同步声音；保存选择状态，轮询不打断输入，切换项目/视图停止旧声音。
6. 运行原有后端与交互测试及新增行为测试；在独立测试资料库通过真实浏览器走通并对抗快速点击、重复保存、重开、范围变更。
7. 写明修改位置、测试证据、环境及限制，更新本机工作台。

验收命令：`.venv/bin/python -m unittest discover -s tests -p 'test_*.py'`；`node --test tests/test_interaction.cjs tests/test_clips.cjs`。浏览器验收步骤与结果另存 qa/clip-flow 与 docs/research。
