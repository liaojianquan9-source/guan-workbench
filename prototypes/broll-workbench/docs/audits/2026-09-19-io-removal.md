# I/O 下线删除报告

日期：2026-09-19

本报告记录拉片工作台中手动 I/O 入点、出点及全局选区功能的删除边界、保留的兼容能力与已执行验证。【完成】表示已在当前工作区核对或测试；【未完成】表示本次未实施或未验证，不得当作已交付。

## 删除边界

- 【完成】下线时间线上的 I、O 和清除选区控件，以及入点、出点拖拽手柄和选区遮罩。
- 【完成】删除全局 `S.in` / `S.out`、`mark-in` / `mark-out` / `clear-range` / `export-audio` 动作和 `rangeEndpoint` 计算链。
- 【完成】删除 I、O、U、P 的功能快捷键及设置项；启动时会过滤旧快捷键配置，这些按键不再被占用。
- 【完成】不再按项目恢复 `lapian:selection:<projectId>` 选区；启动时删除此类旧本地键。
- 【完成】画面轨道拖动只定位播放头，不再建立隐式播放范围。
- 【完成】原 `crop-range` 画面操作已明确为 `split-picture`：剪刀只在当前播放头切开镜头，不读取 I/O 选区。
- 【完成】删除手动选区声音的新建入口和服务端生成方法；`POST /api/projects/{id}/audio` 现返回 405，不会写入项目或生成文件。
- 【完成】删除基于自由 I/O 范围新建研究分镜的旧链路。

## 保留的兼容与触发方式

- 【完成】保留已存研究分镜及其 `start` / `end`、标题、画面、字幕、笔记和声音历史；这些是用户资料，不是已删除的临时 I/O 状态。
- 【完成】点击已存研究分镜后，播放边界直接来自该分镜本身的开始和结束时间；“循环播放当前片段”也只对该对象生效。
- 【完成】点击原片镜头只定位到镜头开始时间，不会偷偷创建研究记录或限制播放。
- 【完成】音乐段的“试听本段”使用一次性试听边界；到段尾后自动清除，不覆盖已选研究分镜。
- 【完成】研究分镜的“声音”页签仍可“保存片段原音”，并可对选中分镜分离人声与背景声。
- 【完成】保留旧 `audio_clips` 记录与文件的列表、读取、试听、下载、标签、来源定位和移除能力；下线的只是新建手动选区声音。
- 【完成】保留整片 `source_audio`、人声/背景声分离、音乐分段、分镜剪切/合并/撤销和媒体 HTTP Range 播放。
- 【未完成：不属于本次删除范围】当前没有用于新建研究分镜的非 I/O 替代入口；原生产界面本来也没有可用的新建入口。未来如需要，应另行设计“选中镜头后加入研究分镜”等显式操作，不应恢复全局 I/O。

## 验证项目

- 【完成】活跃前端静态检查：无 `S.in` / `S.out`、`mark-in` / `mark-out`、`clear-range`、`export-audio`、`source-range-handle`、`timeline-io`、`io-range-status` 或 `rangeEndpoint` 残留。唯一与旧 selection 相关的活跃代码是删除旧本地键的兼容清理。
- 【完成】前端完整回归 77/77 通过：I/O 删除防回归、已存分镜播放、音乐段试听、剪刀/合并、时间精度与预览清晰度切换均通过。
- 【完成】后端完整回归 94/94 通过：已删除的 `/audio` POST 返回 405 且不写数据；历史声音记录及文件在重开后仍完整可读。自动测试使用临时资料库，未使用生产资料。
- 【完成】完整 `verify.command` 通过，共 171 项回归；Python/JavaScript 语法和镜头识别、声音分离、歌曲识别三套本地运行环境均通过。
- 【完成】真实浏览器验收通过：页面无 I/O 控件、拖拽手柄、旧状态提示或相关快捷键；音乐“试听本段”显示独立试听边界，收起后边界立即清除；页面无控制台错误。
- 【完成】重启后的真实服务验证通过：`POST /api/projects/{id}/audio` 返回 405，旧 M4A 地址返回 200，系统资源页正常显示约 23.7 MB 内存。
- 【完成】生产资料在重启和真实页面验收前后均为 218 个文件、约 437.9 MB，逐文件 SHA-256 完全一致。
- 【完成】本报告列出的 11 份 2026-09-18 历史 I/O 相关文档已在标题下方加入下线提示，历史正文未改写。
- 【完成】`README.md`、`PRODUCT.md`、`DESIGN.md`、`docs/backend-api.md` 与 `docs/backend-verification.md` 已更新为下线后的当前口径。
