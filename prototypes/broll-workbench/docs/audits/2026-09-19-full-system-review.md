## 方法说明

本轮使用 Code 工作流将修复拆成小批次，每批先证明失败路径再修复，最后由 `verify.command` 统一复验。Security Auditor 工作流使恢复包、项目元数据、URL、文件名、锁文件和外部 HTTP 响应都按不可信输入处理，直接导致了 XSS、链接文件和固定 HTTPS 主机等加固。
