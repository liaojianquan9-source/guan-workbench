**这次更新的重点，是把选中的一段 B-roll 保存成一个可以反复研究的片段，让它的关键画面、声音、字幕和笔记放在一起。**

## 1. 这次具体更新了什么

### 【已验证】新增“片段”，可以保存一段连续内容

以前，保存的图片和声音主要是分开的记录。这次在右侧“素材收集”里增加了“片段”入口，用一个片段把研究内容收在一起。

你可以在原视频中标记起点和终点，为这段内容命名。一个片段可以跨多个自动识别出的镜头，不必局限于一个镜头。片段卡片会显示名称、原片时间、时长和已保存的画面数量。

**这里的“保存片段”，目前保存的是来源和起止范围。播放仍使用原视频，暂不生成新的 MP4 文件。**

修改位置、验证方法、环境：见证据表 **E1**。

### 【已验证】一个片段可以保存多张关键画面

进入片段后，把视频停在想研究的位置，用左右方向键逐帧调整，再点“保存当前关键画面”或按默认快捷键 E。

每张图都保留原视频中的时间。点击图，可以返回当时的画面。同一帧连续点击保存，只保留一条记录；保存另一帧，就成为这个片段的下一张图。图片以 PNG 保存。

这里的“关键画面”由你选择，当前没有自动判断它是不是“入场结束后的最佳画面”。

修改位置、验证方法、环境：见 **E2**。

### 【已测试但有限制】新增片段内的人声、背景声回听

“声音”页默认使用原音。需要单独研究声音时，点“分离试听”；处理完成后，可以切换：

| 回听方式 | 听到的内容 |
|---|---|
| 原音 | 视频本来的声音 |
| 人声 | 模型分离出来的人声，可能残留背景声或漏掉部分人声 |
| 背景声 | 模型分离出来的背景声音，可能同时包含音乐和音效 |

播放、暂停、定位、音量和静音由同一组播放器控件控制。切换声音时，画面仍对应原视频的同一位置。可以循环回听，关闭循环后会在片段出点停住。

处理过程有状态提示，可以取消、重试；同一范围已有结果时可以复用。加速处理失败时，会尝试本机兼容模式。

**短样本已经跑通；分离结果是否干净、旁白是否完整，还没有通过人耳质量验收。** 波形仍显示原音，界面标为“原音波形”。

修改位置、验证方法、环境：见 **E3、E4**。

### 【已验证】片段里能查看对应字幕、记录时间点笔记

片段详情增加“字幕”和“笔记”入口。

字幕页显示与片段范围重叠的已有字幕，点击后定位回听。此次新增的是片段内的筛选和定位，没有更换原来的字幕识别模型。

笔记会记住原片时间，方便回到当时的画面或声音。输入中的文字草稿保存在当前浏览器；点击保存后，笔记写入本机项目记录。

修改位置、验证方法、环境：见 **E5**。草稿保存机制有代码依据；已保存笔记的重开恢复经过浏览器验证，未验证清除浏览器数据后恢复未保存草稿。

### 【已验证】补齐改名、改范围和重新打开的逻辑

| 你的操作 | 当前处理方式 |
|---|---|
| 修改片段名称 | 更新显示名称；已有图片和声音文件保留原文件名 |
| 修改片段起止范围 | 旧声音保留到历史结果；新的范围可以重新处理 |
| 原来的图或笔记落到新范围外 | 标出“已在范围外”，保留记录 |
| 点击范围外的来源记录或其他镜头 | 回到整条视频，并定位到对应原片时间 |
| 重新打开工作台 | 恢复正在研究的片段和播放位置 |
| 返回整条视频 | 退出片段范围播放，继续查看完整原片 |

修改位置、验证方法、环境：见 **E1、E2、E4、E5**。

## 2. 现在的操作顺序

**打开视频 → 设入点 I → 设出点 O → 保存并命名片段 → 在右侧研究画面、声音、字幕和笔记。**

| 所在位置 | 你要做的事 |
|---|---|
| 视频下方 | 点“设入点 I”“设出点 O”，确定研究范围，再点“保存为片段” |
| 素材收集 → 片段 | 打开已有片段，或者改名、调整范围 |
| 关键画面 | 停住、逐帧查看、保存多张图片 |
| 声音 | 直接回听原音，或分离后切换人声 / 背景声；需要时开启循环 |
| 字幕 | 查看对应文字，点击跳到那句话的位置 |
| 笔记 | 记录当前时间点值得研究的地方 |
| 回到整条视频 | 继续寻找下一个值得研究的片段 |

以上顺序在独立测试资料库走过；对应证据见 **E1—E5**。正式工作台仍使用 [原来的本机地址](http://127.0.0.1:4182/)。

## 3. 文件叫什么，保存在哪里

### 【已验证】新保存的关键画面和声音使用可读文件名

命名包含：**来源名称、片段序号、你的片段名称（如果自定义了）、画面序号或声音类型、原片时间。**

本次测试实际生成的文件包括：

| 文件 | 实际文件名 |
|---|---|
| 第二张关键画面 | `lapian-ui-12s_片段01_数值变化研究_画面02_00m05s133.png` |
| 片段原音 | `lapian-ui-12s_片段01_跨镜头研究_原音_00m00s500-00m06s833.wav` |
| 分离人声 | `lapian-ui-12s_片段01_跨镜头研究_人声_00m00s500-00m06s833.wav` |
| 分离背景声 | `lapian-ui-12s_片段01_跨镜头研究_背景声_00m00s500-00m06s833.wav` |

图片和声音名称里的片段标题不同，是因为测试中把“数值变化研究”改名为“跨镜头研究”；已保存的图片不会被跟着改名。

正式资料都在应用的 [data 文件夹](</Users/liaojianquan/Documents/ChatGPT/B-roll 剪辑/prototypes/broll-workbench/data>) 中。每个视频有自己的项目文件夹，每个研究片段也有独立文件夹。片段详情中展开文件名，可以看到实际目录，并点“在访达中显示”。

下面这些规则也纳入了实现：片段编号不因改名或删除而重新排序；文件名中的斜杠、冒号等会替换；重生成遇到已有同名文件时使用 `_v02` 等后缀，避免覆盖。

证据：**E1、E2、E3**。不同浏览器下载“副本”后的重名处理规则尚未逐一验证，由浏览器和系统决定。

## 5. 测试到了什么程度

### 【已验证】基础记录和操作

保存的测试结果是：**后端 28 项通过；前端时间与交互规则 16 项通过。** 这两个数字包含原有测试，本轮新增的是 7 项后端测试和 5 项前端规则测试。

真实浏览器中走过了跨镜头保存、两张关键画面、重复点击、保存笔记、改名改范围、刷新恢复、字幕定位、范围外来源定位、取消分离、重新分离、声音切换、循环和静音。测试使用独立资料库；正式项目记录重启前后内容校验值一致。

测试位置、日志和环境：见 **E1—E7**。

### 【已测试但有限制】声音效果与速度

实测一个 **6.33 秒片段，声音分离总耗时约 8.79 秒**，包括声音提取、启动程序、加载模型和处理，不包括首次安装及模型下载。原音、人声、背景声的长度一致。播放同步两次抽查的差值约为 **26 毫秒、10 毫秒**。

这些结果只代表这台 Mac 和测试短片段，不能外推为长素材、批量素材或其他电脑的速度、精度保证。证据见 **E3、E4**。

测试中曾出现一次加速子进程失败，之后实际重试成功，初次原因未稳定复现。已经加入失败记录和兼容模式重试；兼容模式路径通过模拟失败测试，不能据此宣称所有异常都能恢复。

## 6. 哪些还没有纳入这一版

以下边界在本轮验收记录中有明确说明，当前不能算作可用的新功能：

- **自动挑选最佳关键画面**：目前由你手动选择；没有自动判断“入场结束”或“画面完全落定”。
- **Silero VAD 正式接入**：仍停留在之前的实验状态，未启用到正式转录流程。
- **片段 MP4、片段级字幕和分镜表导出**：相关命名可以按已有方案继续实现，本轮没有做这些导出。
- **整套 UI 改版**：本次沿用现有界面，只补必要入口和操作。

**【推测】后续优先级：先用不同类型的真实素材确认研究流程是否顺手，再决定是否加入自动候选画面和额外导出。**
