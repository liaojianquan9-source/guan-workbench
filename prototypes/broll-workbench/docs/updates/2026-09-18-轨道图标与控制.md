# 轨道图标与控制

日期：2026-09-18。修正上一版把轨道头做成文字说明和试听按钮的问题，改为用户要求的剪辑器控件。

## 【已验证】界面与操作

每层从左到右：**轨道类型图标 → 锁 → 眼睛 → 静音喇叭 → S**。

三层类型图标依次为播放器、人头、小喇叭。轨道头不再显示“原片段／人声／背景声”、说明段落或“试听”按钮；鼠标悬停可以看名称与作用，键盘及辅助阅读标签保留。

| 控件 | 实际行为 |
|---|---|
| 锁 | 锁定后保护片段共同起止范围，并阻止移除片段；仍可播放、定位和改名。 |
| 眼睛 | 隐藏/显示该轨内容。原片轨还控制视频画面的显示；声音轨控制波形显示。声音不受眼睛开关影响。 |
| 喇叭 | 独立控制该轨是否发声。 |
| S | 只播放这一轨，再点取消；恢复其它轨道原有的静音状态。静音优先于 S。 |

统一使用上方播放键。点轨道只定位，不再偷偷切换声音。首次打开默认原片轨 S 亮起；取消 S 后由各轨静音开关决定同时播放哪些声音。原声关闭后，可同时听人声与背景声。

轨道状态按片段保存在当前浏览器本机。最终示例已恢复为全部显示、解锁，原片轨 S 开启，暂停在片段起点。

## 【已测试但有限制】边界

- 锁定是当前浏览器内的编辑保护，状态不跨浏览器同步；没有将它宣称为后端权限锁。
- 目前三轨共用片段范围，所以任一轨锁定都会保护共同范围；尚无单轨独立裁剪或拖动功能。
- 本轮浏览器验证使用 11.5 秒样本，不能替代长素材、多设备持续同步测试或声音分离质量评价。
