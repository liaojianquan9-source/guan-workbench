# 拉片基础操作、完整画面与人声：能力核对

> **⚠️ 历史记录：I/O 已于 2026-09-19 下线、仅作当时留档。**

2026-09-18。依据当前工程和开源项目的一手说明。基础操作已修正；自动选取最终画面、人声检测、声音分离在本轮只做研究，没有新增入口或安装模型。

## 基础操作本轮实际修改

- 点击分镜到镜头首帧，移除原先额外加一帧的偏移。
- 上下切点导航按帧比较，移除固定 0.1 秒容差；从切点前一帧向前跳，不能跳过这个切点。
- 镜头高亮与导航使用一致的帧边界，避免切点小数舍入造成上一镜头仍高亮。
- 时间轴获得焦点后，空格、方向键和原有拉片快捷键继续生效。文字输入框、音量和缩放控件保持各自的键盘操作。
- 时间轴获得焦点后继续同步播放进度；Home/End 定位片头/最后可显示帧。
- ↑ 到前一个切点：在镜头内部先回本镜头开头，再按一次到上一镜头。↓ 到后一个切点。

验证：11 项交互自动测试通过，其中新增 2 项覆盖临近切点与 23.976、29.97、30、30.000003708、60、120 fps。浏览器在独立测试资料库完成验证：5.10 秒向下跳到 5.133333 秒；点击第三镜头到 6.833333 秒，第三镜头高亮；后退一帧到 6.80 秒，第二镜头高亮；再跳切点回 6.833333 秒。时间轴聚焦后空格能播放，方向键能暂停并逐帧，两个时间轴数值同步，浏览器无错误日志。

本轮未修改后端，未重跑后端整套测试；未修改正式媒体或正式项目记录。上述定位使用项目记录的帧率；可变帧率视频的逐帧时间戳精度没有在本轮验证。

## 完整画面与最终画面

TransNetV2 输出镜头切换位置。当前截图由 FFmpeg 从项目视频直接导出完整画面，保留视频像素尺寸；当前格式为高质量 JPEG。

当前分镜缩略图取镜头开始后约 0.08 秒，短镜头取中间位置。这没有判断入场是否结束，也没有判断所有元素是否到齐。

需要区分：

1. 完整尺寸画面：已经能截图。
2. 长时间几乎不变的画面：FFmpeg freezedetect 可提供静止区间；黑屏和空背景也可能满足条件。
3. 元素都出现、入场结束且出场未开始的画面：需要专门的候选帧筛选。建议在镜头内比较连续帧和局部运动，排除切换、黑场、模糊，给出少量候选供人确认。该方案尚未实现或验证准确率。

OpenCV 的帧间比较和光流可以测量变化与运动，但不能直接证明内容完整。始终运动的背景、人物、循环动画，以及先出现后消失的文字，都可能让“最静止”与“最终画面”不一致。如果元素从未同时出现在原视频里，就没有可直接截取的完整最终帧。

## 人声检测与分离

用户已明确：主要询问能力是否可行，人声判断与人声/背景音乐分离都在关注范围。

- 人声活动检测：Silero VAD 给出可能存在说话声的区间。Whisper 转写给出说话内容。当前工程的 whisper.cpp 支持接入 Silero，但当前转写脚本未启用它。未来可以复用现有运行程序，增加对应模型文件与参数，保持本地运行。检测仍会有漏检或误检。
- 声音分离：当人声与音乐已经混在一个音轨中，需要源分离模型来估计两条声音。python-audio-separator 可作为 Python 组件或命令行工具集成，支持多种 UVR 模型及 Mac 运行路线。实际选哪个模型需要用带旁白、音乐、音效的素材试听；歌曲人声分离质量不能直接代表旁白分离质量。输出可能残留串音或产生失真。
- VAD 不能把声音分开，也不能判断声音是不是拍摄现场原声或后期配音。
- 若原文件本来就有独立人声与音乐轨道，可直接提取音轨，无需声音分离模型；目前未核实用户原视频是否含分开的音轨。

## 可复用项目与接入结论

| 项目 | 作用 | 当前结论 |
| --- | --- | --- |
| [TransNetV2](https://github.com/soCzech/TransNetV2) | 镜头切点 | 已使用；不负责理解最终画面 |
| [FFmpeg](https://github.com/FFmpeg/FFmpeg) | 截图、音轨提取、静止检测 | 已使用截图/媒体处理；可复用内置静止检测，但尚未接入选帧 |
| [OpenCV](https://github.com/opencv/opencv) | 帧间比较、局部运动 | 最终画面候选筛选的组件，需编写并验证产品规则 |
| [Silero VAD](https://github.com/snakers4/silero-vad) | 判断说话区间 | 可接入现有 whisper.cpp；尚未启用 |
| [python-audio-separator](https://github.com/nomadkaraoke/python-audio-separator) | 混合音轨的人声/伴奏分离 | 可嵌入后台；仅候选，尚未安装或测试 |
| [wavesurfer.js](https://github.com/katspaugh/wavesurfer.js) | 波形、时间刻度、声音选区 | 可用于以后替换现有波形控件；当前基础交互已能直接修复，不为此整套替换 |

一手文档：[FFmpeg freezedetect](https://ffmpeg.org/ffmpeg-filters.html#freezedetect)、[OpenCV 光流](https://docs.opencv.org/4.13.0/d4/dee/tutorial_optical_flow.html)、[whisper.cpp VAD](https://github.com/ggml-org/whisper.cpp#voice-activity-detection-vad)。这些现成组件不等于已完成本产品的功能；本轮接入状态如上。
