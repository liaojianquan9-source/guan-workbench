# 片段保存、关键画面、声音回听与来源定位验收记录

> **⚠️ 历史记录：I/O 已于 2026-09-19 下线、仅作当时留档。**

2026-09-18。本轮只针对已确认的拉片研究流程，沿用现有界面。产品定义：帮助自媒体创作者快速看懂 B-roll 里有什么、哪个画面能用、声音是什么内容。

## 【已验证】现在怎样操作

1. 导入/打开视频，在想要的起点点“设入点 I”，到结束位置点“设出点 O”，再点“保存为片段”。可以跨多个镜头。
2. 填名称，进入右侧“素材收集 → 片段”。这一步保存来源和范围，播放仍使用原视频，尚不生成新的 MP4。
3. 在“关键画面”停住、逐帧调整，点保存或按 E；一个片段可有多张 PNG。点击图片返回它的原片时间。同一帧重复保存只保留一条。
4. “声音”默认直接播放原音。点“分离试听”，完成后选择人声或背景声；上方播放器统一控制播放、暂停、定位、音量和静音。“循环”让当前片段反复播放；关闭循环则在出点停住。
5. “字幕”只显示与片段范围重叠的已有字幕，点击定位。“笔记”绑定原片时间，文字草稿保存在当前浏览器；保存后写入项目记录。
6. 改名不移动旧文件；调整范围会标出范围外的旧画面/笔记，旧声音放进历史结果。点击范围外的来源记录或镜头，会退出片段范围并准确返回原视频，而不是强行吸附到片段边缘。
7. 重新打开会恢复正在研究的片段和位置。点“回到整条视频”退出范围播放。

验证环境：本机 MacBook Air M4 / 16 GB，macOS 26.5，Python 3.12.14，FFmpeg 8.1，Node 24.13.0，Codex 内置浏览器。浏览器主流程使用独立 4192 测试资料库，素材是用户指定黄仁勋视频的 12 秒片段；正式 4182 页面做只读入口检查。

## 【已验证】文件实际保存规则

项目目录下按 `clips/片段内部ID/` 分开保存，同名来源也不会混在一起。界面显示友好名称，内部 ID 只用于稳定关联。

本次真实文件示例：

- `lapian-ui-12s_片段01_数值变化研究_画面02_00m05s133.png`
- `lapian-ui-12s_片段01_跨镜头研究_原音_00m00s500-00m06s833.wav`
- `lapian-ui-12s_片段01_跨镜头研究_人声_00m00s500-00m06s833.wav`
- `lapian-ui-12s_片段01_跨镜头研究_背景声_00m00s500-00m06s833.wav`

来源/标题中不可作为文件名的字符会替换为下划线，长标题只截短文字部分；保留片段序号、画面序号、来源时间。重生成遇到已有同名文件会使用 `_v02` 等后缀，不覆盖。用户下载“副本”后的冲突名称由浏览器/系统管理，本轮未验证所有浏览器的下载命名行为。

## 【已测试但有限制】不能当成全面验收的部分

1. 声音分离不是旁白内容识别。使用 [audio-separator 官方项目](https://github.com/nomadkaraoke/python-audio-separator) 的 0.47.0 版本及公开 MDX 模型 `UVR-MDX-NET-Inst_HQ_3.onnx`，本地运行，没有上传音频到 API。模型文件约 64 MiB，组件独立安装于 `.venv-separation`；确切依赖见锁文件。
2. 另一个 8 秒样本的三路采样数相等；人声与背景声相加后，与原音的互相关峰在 **0 个采样点偏移**。这说明该样本的信号时序没有整体平移，不能证明旁白完全保留、音乐完全去除。没有干净的人声/背景声真值，本轮未做人耳质量验收。
3. 曾有一次加速任务子进程失败，之后实际重试成功；初次失败原因未稳定复现。已增加失败日志和 CPU 回退，回退路径经过故障注入测试，不宣称能恢复所有模型异常。
4. 播放同步是浏览器视频时钟驱动，超过约 60 毫秒偏差时纠正，并处理暂停/定位/循环；上述只是短样本抽查，不是长视频或所有设备的延迟保证。后台标签页的节流、可变帧率逐帧精度仍需另测。
5. 自动找“入场结束后的最佳画面”尚未接入。当前关键画面由用户选择；既有镜头缩略图自动选帧规则未在本轮替换。没有把固定偏移或低运动分数包装成“最佳定格帧”。
6. Silero VAD 保持此前实验状态，未启用在正式转录流程；波形仍显示原音，界面明确写“原音波形”，没有更换波形控件。
7. 本轮不生成片段 MP4、不新增字幕/分镜表的片段级导出。已确认的相应文件命名方案保留在流程方案中，不能称为已实现。

## 【推测】下一轮适合验证的内容

先用不同类型的真实 B-roll 连续研究，判断手动保存多图是否顺手，并对照原音听分离结果。只有确认候选选帧能省时间，再接入自动候选；现有模块已经分开，后续可以改界面布局而保留项目记录、文件命名和处理接口。
