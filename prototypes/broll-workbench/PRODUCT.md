# 观 · 拉片工作台

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

用户在本机研究参考视频的画面、声音与剪辑方式；主要工作环境为桌面浏览器。

## Product Purpose

浏览视频素材，查看可跨镜头的已保存研究片段，逐帧核对、分轨回听，保存关键画面和时间点笔记，并准确返回来源。

## Operating Context

用户明确选择“浏览素材与深入研究有清楚的切换”。素材库与研究台都要好用。图像、缩略图和真实 UI 状态优先于大段文字；保留必要标签与帮助。

## Capabilities and Constraints

现有 HTML/CSS/JavaScript 与 Python 本机服务。保留当前后端和真实数据；保留逐帧、自动镜头、字幕、音乐识别、收藏与导出能力，不再提供手动入点/出点或选区声音导出。已保存研究片段仍是来源 `start` / `end` 记录，不是另存 MP4；历史 `audio_clips` 继续兼容读取。三轨共用原片时间尺，背景声包含音乐和音效。用户已明确要求轨道类型图标、锁定、眼睛、静音和 S 控件。

## Brand Commitments

中文界面；现有名称为「观」（Guan，取自《易经》观卦）。用户要求整体视觉与交互改版，允许使用开源 UI 内容。

## Evidence on Hand

本机资料库内真实视频、镜头缩略图、关键画面、波形、字幕与声音文件。不得为展示而虚构片段、笔记或歌曲。

## Product Principles

- 浏览与深入研究保持清楚的切换和返回路径。
- 研究内容始终可以回到原视频。
- 高频操作立即响应，长任务明确反馈。
- 界面围绕素材与观察组织，媒体内容决定视觉重点。
- 播放器、轨道和研究资料分别组成圆角卡片，用留白建立关系，避免横竖分隔线与表格式轨道。
- 分镜与已有分轨直接在主时间线上共存。点击原片镜头只定位；打开已保存研究片段时，同一播放器按其 `start` / `end` 回放。
- 复刻审批始终使用左任务、中审查画面、右审批三栏；每个片段任务内显示原视频缩略图和 Skill 定义的可变数量落定静态帧，右侧汇总该片段布局门。选择静态帧只做同屏联动，不产生页面跳转；每个静态帧分别批准，片段内全部通过后才允许进入动效分析，再进入完整特效生成。


### 分镜与片段播放

- 研究资料统一在「分镜」查看原片镜头、已保存研究片段及关联画面、声音和笔记。
- 时间线不提供手动入点/出点按钮、快捷键、拖拽选区或范围端点。
- 点击原片镜头只定位到该镜头起点，不创建选区，不新建或修改研究片段。
- 打开已保存研究片段后，播放器直接使用其 `start` / `end` 作为回放边界；不将该边界写入临时选区。
- 剪刀只在当前播放头按帧切开画面，与片段播放边界无关。
- 不再从手动时间范围新建声音片段。历史 `audio_clips` 仍可试听、下载、定位、标签和移除。

### 预览清晰度
- 播放器右上角 HQ 菜单提供原画、标准（宽高约 1/2）、流畅（宽高约 1/4）。
- 首次使用低清档位会在本机生成独立预览缓存，等待时继续播放当前画质。
- 切换保留位置、播放/暂停状态与速度，按视频记住所选档位。
- 分镜识别、字幕、音轨、截图和导出继续使用原片；不修改原视频与研究记录。

### 音乐分段
音乐与音效保持在背景声中，不尝试分离二者。拉片完成整片声音处理后，生成音乐变化的建议分段；用户可在播放头切开，修改相邻段的时间分界，合并与撤销。点击背景声段进入右侧音乐详情；“试听本段”使用音乐模块的独立临时范围，到该段结束后停止，不创建研究片段或持久选区。自动分段是声音变化建议，不是已确认的换曲判定。

### 按需启动分析（替代此前进入拉片自动分析的规则）
导入视频只准备可播放媒体和浏览预览。进入拉片、打开画面或字幕面板不自动启动分析。用户在时间线顶部点击「画面切分」「转文字」「音乐分段」后，才执行对应任务。音乐分段需要的背景声准备属于该次显式操作；不启动整片识曲。已有分析保留并可查看。音乐块用于展示建议换曲位置、单独回听至该段末尾和调整分界。

### 试听声音来源
原片原声与分离后的人声/背景声互斥播放。取消 S 时，有分轨的范围默认混合人声与背景声，原声自动静音；切回原声会停止分离轨道。分轨的静音、单独播放和总静音保持有效，双轨静音不回退原声。独立声音资料试听与主播放器也互斥。

### 波形和音轨音量
波形采用单边细竖条，条高表示声音强弱。原声、人声和背景声分别提供可拖动的试听音量线，中间 0 dB 保持原音量，上拉增强、下拉减弱；双击恢复 0 dB。增益范围 −60 至 +12 dB，并按项目保存在本机。轨道锁定后不可调节。

### 画面手动裁切与合并（2026-09-18）

剪刀在当前播放头按帧切开画面，不依赖任何临时播放范围。画面轨点选一段、Shift 点选相邻一段后点击合并；也可以先开启合并选择再点击两段。合并不作用于文字与声音。提供最近 20 次画面边界调整的撤销，并在镜头或笔记发生后续修改时阻止覆盖。原视频不重新编码。

### 字幕改字（2026-09-18）

双击右侧字幕行或时间线文字可在右侧行内编辑。保存后保持原时间码，同步导出文字。单击仍用于定位；保存/取消和快捷键均支持。字幕导出统一位于播放器右上角“⋯ → 导出原片字幕”。
