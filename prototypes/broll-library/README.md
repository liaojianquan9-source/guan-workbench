# B-roll 样式库 · 来自真实案例的样式

本地预览：http://localhost:4178/ 。旧的 `?view=a`、`?view=b` 链接均进入同一页面。

根据用户最新要求，页面只使用两个真实 Kimi 复刻案例。此前两稿的切换、六个临时原创动画及相关代码/媒体均已删除。当前以每一种表达样式为素材单位，保留完整案例作为转场与上下文参考。

## 素材结构

| 编号 | 样式 | 所属案例内的帧区间（左闭右开，30fps） |
| --- | --- | --- |
| SHOT-001 | 开头大字标题 | 案例一 0–99 |
| SHOT-002 | 大数字参数展示 | 案例一 99–172 |
| SHOT-003 | 月球主题产品标题 | 案例一 172–300 |
| SHOT-004 | 问题引入标题 | 案例二 4–80 |
| SHOT-005 | 文章标题高亮 | 案例二 80–177 |
| SHOT-006 | 提示词输入演示 | 案例二 177–339 |
| SHOT-007 | 双列指标比较 | 案例二 339–428 |

文章一、过渡、文章二归为一种文章表达样式；提示词的放大、卡片、无框形态保留为一段连续演示。原片的前后转场仍可通过完整案例播放查看。

## 每条素材可以查看什么

- **动效预览**：从现有成片精确切出的独立预览；可切换完整案例及原片上下对照。
- **替换示例**：之前制作中真实留下的测试静帧，提供原图与替换图及原始配置下载。
- **模板与代码**：本样式的修改字段说明，所属案例的完整 Remotion 源码包、参数、布局和动效记录。

三个来自案例一的替换配置是原有单项测试；案例二的四个替换配置是原有组合测试，页面已有说明。问题引入的替换图来自批准静态基准，其余案例二替换图来自动态取样。替换静帧不代表任意内容实时修改已接入页面。

原有「文章标题高亮」早期模板放在对应样式下作为关联参考，它不是当前完整案例实际加载的模板。

平台标识和底部口播字幕在素材/替换预览中继续排除。原片对照保留原始证据并标识原片位置。

## 功能与边界

搜索、按案例筛选、收藏、分样式播放、查看替换效果、查看/下载代码与配置均可使用。收藏仅保存在当前浏览器；AI 自动选片、页面内实时改字和修改后视频导出尚未接入。

各预览视频是已有成片的精确切片。源码包保留实际案例和连续转场，未把原工程重构成七个独立渲染组件。原始案例目录未更改。

## 文件与验证

- `src/data.ts`：2 个案例、7 种样式及真实资源映射。
- `src/App.tsx`、`src/style.css`：单一素材库页面。
- `public/media/`：已有视频、7 个切片、真实场景与替换静帧。
- `public/resources/`：实际源码、配置、素材清单及 2 个源码包。
- `public/resources/shot-preview-manifest.json`：切片来源与帧数核验。
- `public/resources/shot-replacement-manifest.json`：替换图与原始配置来源。
- `public/resources/source-pack-verification.json`：源码包完整性检查。

类型检查、构建和 44 条资源路径检查通过。7 个切片均已完整解码，帧数和时长正确；7 张替换图逐张检查，无平台署名或底部口播字幕。两个源码包的 CRC、相对引用与原文件一致性检查通过。
